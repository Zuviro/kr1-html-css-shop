# Pumpkin — осенние декорации

Многостраничный учебный сайт каталога товаров для дома: главная, каталог, карточка товара, заявка, контакты и страница частых вопросов.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Структура проекта

```
kr1-html-css-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── contacts.html
├── faq.html
├── css/
│   └── style.css
├── js/

```

## Используемые технологии

- HTML5 — семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3 — внешний файл стилей, CSS-переменные, Flexbox, CSS Grid, позиционирование (`relative`, `absolute`, `sticky`, `fixed`)
- Минимальный JavaScript — открытие/закрытие `<dialog>` и обработка отправки формы
- Git, GitHub, GitHub Pages

## Страницы проекта

| Страница | Назначение |
|---|---|
| `index.html` | Главная: hero-блок, популярные товары, блок преимуществ |
| `catalog.html` | Каталог: фильтры в `<aside>` и сетка карточек |
| `product.html` | Карточка товара: изображение, описание, таблица характеристик, кнопка заявки |
| `order.html` | Форма заявки с валидацией |
| `contacts.html` | Контактная информация и форма обратной связи |
| `faq.html` | Частые вопросы (самостоятельная доработка) |

## Реализованные элементы

- Единая навигация со всех страниц + якорные ссылки (`#popular`, `#advantages`, `#contacts`)
- Карточки товаров в CSS Grid с бейджем «Скидка» (`position: relative` + `absolute`)
- Sticky-шапка (`position: sticky; z-index: 100`)
- Sticky-фильтр каталога (`position: sticky` в `<aside>`)
- Фиксированная кнопка «Наверх» (`position: fixed; z-index`)
- Таблица характеристик товара (`caption`, `thead`, `tbody`, `th`, `td`)
- Модальное окно на `<dialog>`
- Формы заявки и обратной связи с HTML5-валидацией (`required`, `type="email"`, `pattern`)
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`
- Хлебные крошки на внутренних страницах
- БЭМ-именование классов
