# Lumen

Учебный HTML/CSS-проект небольшого каталога настольных ламп.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог;
- `contacts.html` — контакты;
- `css/style.css` — общие стили;
- `js/main.js` — минимальная работа модального окна и формы;
- `images/` — изображения проекта.

## Технологии

HTML5, CSS3, минимальный JavaScript.
